# 🐍 Python Foundations — Small Learning Exercises

These **original, introductory examples** demonstrate basic Python input handling, arithmetic and conditional statements. They are not production banking or fuel-pricing software.

- [ATM withdrawal exercise](atm_withdrawal.py) — checks valid numeric input, positive withdrawal and available balance.
- [Fuel cost estimate](fuel_cost.py) — calculates estimated litres and total cost using a clearly stated efficiency assumption.

Run locally with Python 3:

```bash
python atm_withdrawal.py
python fuel_cost.py
```

No customer records, financial accounts, authentication credentials or business data are used.
